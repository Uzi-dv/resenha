Resenha para Windows

Voz, chat e transmissão de tela com os seus amigos.

O app é para computadores com Windows. No celular, use o Resenha pelo navegador.

Baixar para Windows

Instalador para Windows 10 e 11

  • Usar no navegador
  • Versão portátil (sem instalar)

Como instalar

  1. Abra o Resenha-Setup que você baixou.
  2. Se o Windows mostrar “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo. O aviso aparece porque o app não tem assinatura digital.
  3. Pronto. Daqui em diante, o Resenha se atualiza sozinho.

Requisitos

Windows 10 ou 11, 64 bits.
